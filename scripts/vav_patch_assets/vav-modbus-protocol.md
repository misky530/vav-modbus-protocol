# 变静压 VAV · Modbus 协议表

## 总线参数

| 项 | 值 |
|---|---|
| 协议 | Modbus TCP |
| Slave | `modbus-server` 监听 `0.0.0.0:5020` |
| Unit ID | 通常 `1`（jsmodbus Server 一般可响应） |
| 字节序 | Big-Endian |
| 寄存器区 | Holding Registers |
| 地址约定 | **协议地址从 1 起**；PDU = 协议地址 − 1 |

## 模式切换（像真设备）

- **不是**定时自动切换；默认保持当前模式，过程量按曲线变化。
- 向协议地址 **20** 写 `1` → 切到**正常**模式，随后命令字被清 `0`。
- 向协议地址 **21** 写 `1` → 切到**值班**模式，随后命令字被清 `0`。
- 协议地址 **22** 反馈当前模式：`0` 正常 / `1` 值班（只读）。
- 若 20、21 同时为 1，按**值班优先**处理。
- 本地 Inject「切到正常/值班」仅调试用，等价于置命令字。
